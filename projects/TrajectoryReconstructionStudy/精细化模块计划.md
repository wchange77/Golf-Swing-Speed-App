**目标**：将 TrackMan 数据与帧序列关联，生成发射参数回归模型的训练标签。

**输入**：

**输出**：`datasets/processed/golf_ball_detection/trackman_labels.jsonl`

每条记录格式：
```json
{
  "sampleId": "golf_ball_detection_abc123",
  "sha256": "abc123...",
  "impactFrameIndex": 142,
  "frameWindow": [132, 152],
  "pixelsPerMetre": 487.3,
  "ballSpeedMph": 152.4,
  "launchAngleDegrees": 10.8,
  "spinRateRpm": 2850,
  "spinAxisTiltDegrees": 5.2,
  "backspinRPM": 2839,
  "sidespinRPM": 257,
  "carryDistanceMeters": 218.5,
  "clubType": "driver"
}
```

**核心逻辑**（约 60 行）：
1. 读取 `samples.jsonl`，过滤有 `ballSpeedMph` + `launchAngleDegrees` 的样本
2. 关联 `frames_index.jsonl` 找到 impact 帧（role == "impact"）
3. 计算 `backspinRPM = spinRateRpm * cos(spinAxisTiltDegrees)`
4. 验证帧窗口内图像文件存在
5. 写出 `trackman_labels.jsonl`

**运行**：

### 模块 3D：发射参数估算

**目标**：获取 LaunchConditions，优先级：TrackMan 手动输入 > CoreML 模型 > 查表法。

**数据流**：
```
优先级 1（最高精度）：用户手动输入 TrackMan 数据
  → TrackManLaunchConverter.from(trackman:)
  → LaunchConditions（confidence = 0.95）

优先级 2（模型训练后）：CoreMLLaunchEstimator
  → estimate(frames: impactFrames, pixelsPerMetre: calibration.pixelsPerMetre)
  → LaunchConditions（confidence ≈ 0.80）

优先级 3（fallback）：LaunchConditionEstimator 查表法
  → estimate(clubHeadSpeedMph: metrics.ballSpeedMph / smashFactor, club: clubType)
  → LaunchConditions（confidence ≈ 0.50）
```

**新建文件**：`packages/GolfAnalysisKit/Sources/GolfAnalysisKit/Trajectory/TrackManLaunchConverter.swift`（约 25 行）

```swift
public extension LaunchConditions {
    static func from(trackman: CollectorReferenceMeasurement) -> LaunchConditions? {
        guard let speedMph = trackman.ballSpeedMph,
              let angle = trackman.launchAngleDegrees,
              let spin = trackman.spinRateRpm else { return nil }
        let tilt = (trackman.spinAxisTiltDegrees ?? 0) * .pi / 180
        return LaunchConditions(
            ballSpeedMs: speedMph * 0.44704,
            launchAngleDegrees: angle,
            launchDirectionDegrees: trackman.launchDirectionDegrees ?? 0,
            backspinRPM: spin * cos(tilt),
            sidespinRPM: spin * sin(tilt),
            confidence: 0.95
        )
    }
}
```

```swift
    let trajectoryResult: TrajectoryResult      // 物理仿真结果
    let bezierPoints: [CGPoint]                 // 屏幕坐标曲线点
```

**核心逻辑**：
```

3. 将 TrajectoryResult.points 从米制转屏幕坐标：
   screenX = impactScreenPoint.x + point.x * calibration.pixelsPerMetre
   screenY = impactScreenPoint.y - point.y * calibration.pixelsPerMetre
4. BezierTrajectoryModel 平滑（已有）
5. 取 TrajectoryResult.points.last 作为预测落点
```

- **地址**：[github.com/rucv/golf_ball](https://github.com/rucv/golf_ball)
- **内容**：高尔夫球图像数据集，含标注
- **用途**：补充球检测训练数据

#### 3. TrackNet（高速小目标追踪）
- **地址**：[github.com/weekenddeeplearning/TrackNet](https://github.com/weekenddeeplearning/TrackNet)
- **论文**：[arxiv.org/abs/1907.03698](https://arxiv.org/abs/1907.03698)
- **内容**：羽毛球/网球高速追踪数据集 + 热力图检测方法
- **用途**：TrackNet 的热力图方法比 YOLO bbox 更适合高速运动球（每帧位移 >100px），可作为模块 2A 的备选架构参考
- **关键参数**：输入 640×360，连续 3 帧叠加生成热力图，适配 240fps 场景

### B. 挥杆动作 / 阶段识别类（用于模块 3B impact 检测辅助）

#### 4. GolfDB（CVPR 2019）
- **地址**：[github.com/wmcnally/golfdb](https://github.com/wmcnally/golfdb)
- **论文**：[arxiv.org/abs/1903.06528](https://arxiv.org/abs/1903.06528)
- **内容**：1400 段高质量高尔夫挥杆视频，标注 8 个挥杆事件帧（address → impact → finish）+ bbox + 球杆类型 + 视角
- **用途**：
  - 训练 SwingNet 识别 impact 帧，作为音频检测的备用方案
  - 提供球杆类型标签，辅助模块 3D 查表法选择正确球杆参数
- **下载**：数据集通过 Google Drive 提供，README 有链接

#### 5. CaddieSet（CVPR 2025 Workshop）
- **地址**：[openaccess.thecvf.com — CaddieSet](https://www.openaccess.thecvf.com/content/CVPR2025W/CVSPORTS/html/Jung_CaddieSet_A_Golf_Swing_Dataset_with_Human_Joint_Features_and_CVPRW_2025_paper.html)
- **论文**：[arxiv.org/abs/2508.20491](https://arxiv.org/html/2508.20491v1)
- **内容**：单视角挥杆视频 + 17 关节 3D 姿态 + **15 个挥杆质量指标** + 球信息（速度、方向、落点）
- **用途**：
  - 最接近本项目需求的数据集，含球速/发射角/落点真值
  - 可用于验证模块 2B 回归模型的泛化能力
  - 15 个挥杆指标可扩展 FlightDataPanel 的展示维度
- **注意**：2025 年新发布，需联系作者获取数据

### C. 物理模型参考数据（用于验证模块 3E 轨迹精度）

#### 6. Foresight Sports 发射参数参考表
- **地址**：[help.foresightsports.com — Ball Launch Data Performance Reference Tables](https://help.foresightsports.com/hc/en-us/articles/47208228295187-Ball-Launch-Data-Performance-Reference-Tables)
- **内容**：按球杆速度分档的最优发射角、最优旋转率、预期 carry/total 距离范围
- **用途**：验证 `LaunchConditionEstimator` 查表法的参数合理性，校准 `typicalBackspin[ClubType]` 常量

#### 7. Golf Ball Bounce 实验数据集（arxiv 2023）
- **地址**：[arxiv.org/abs/2302.02758](https://arxiv.org/abs/2302.02758)
- **内容**：1000+ 次高尔夫球落地弹跳实验，视频分析落地前后速度和旋转
- **用途**：改进 `TrajectoryPhysicsModel` 的落地弹跳模型（当前模型落地后无弹跳计算）

### D. 数据集使用策略

```
阶段 1（立即可用）：
  Roboflow Universe golf ball 数据集
  → 合并到 datasets/processed/golf_ball_detection/
  → 与自采数据 7:3 混合训练 2A YOLO 模型
  → 解决冷启动问题（自采数据不足时）

阶段 2（模型优化）：
  GolfDB 1400 段视频
  → 提取 impact 帧附近 ±30 帧
  → 补充球检测训练数据（多视角、多球杆）
  → 训练 SwingNet 作为 impact 检测备用方案

阶段 3（精度验证）：
  CaddieSet（含球速/落点真值）
  → 验证 2B 回归模型在独立数据集上的泛化误差
  → 目标：ballSpeed MAE < 5mph，launchAngle MAE < 2°

阶段 4（物理模型校准）：
  Foresight 参考表 + Bounce 数据集
  → 校准 LaunchConditionEstimator 常量
  → 添加落地弹跳计算到 TrajectoryPhysicsModel
```
