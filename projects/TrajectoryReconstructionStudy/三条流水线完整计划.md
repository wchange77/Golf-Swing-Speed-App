# 三条流水线完整计划

## TrackMan 的核心价值：作为监督信号训练模型

TrackMan 不只是"当前使用的工具"，它是**训练数据的真值标签（ground truth）**。
用 TrackMan 标注的数据训练出的模型，最终可以在没有 TrackMan 的情况下达到接近 TrackMan 的精度。

```
有 TrackMan 阶段（数据采集）→ 训练模型 → 无 TrackMan 阶段（正式使用）
```

---

## 流水线 1：数据收集处理流水线

### 目标
将 iPhone 240fps 视频 + LiDAR 标定 + TrackMan 数据，整理成可用于模型训练的标准数据集。

### 步骤

```
[现场采集]
iPhone (AppleOSDatasetCollectorApp)
  ├─ LiDAR 标定（击球前）→ CollectorCameraSidecar（pixelsPerMetre, ballPosition3D）
  ├─ 240fps 视频录制
  ├─ 音频录制（SwingAudioDetector 定位 impact 帧，±1ms）
  └─ 手动输入 TrackMan 数据 → CollectorReferenceMeasurement
       字段：ballSpeedMph, launchAngleDegrees, spinRateRpm,
             clubSpeedMph, carryDistanceMeters, landingLocation(GPS)
  ↓ iOS 导出（sessions.jsonl + samples.jsonl + 视频 + sidecar）

[Mac 导入]
python tools/import_ios_export.py --input <export_dir>
  → datasets/registry/samples.jsonl（含 TrackMan 字段）

[帧提取]
python tools/extract_frames.py --domain golf_ball_detection --mode impact_window --fps 240
  → datasets/raw/golf_ball_detection/frames/{sha256}/frame_*.jpg
  → datasets/registry/frames_index.jsonl

[预标注]
python tools/prelabel_yolo.py --source ultralytics --weights best.pt
  → datasets/raw/golf_ball_detection/prelabels/{sha256}/frame_*.txt

[人工校正（Label Studio）]
python tools/export_to_labelstudio.py --domain golf_ball_detection
  → Label Studio 校正 bbox
python tools/import_from_labelstudio.py --input ls_export.json --domain golf_ball_detection
  → datasets/annotations/yolo_bbox/{sampleId}/frame_*.txt

[生成训练集]
python tools/export_yolo_dataset.py --write-yaml ../../tools/train_ball_detector/golf_ball.yaml
  → datasets/processed/golf_ball_detection/{train,val,test}/{images,labels}/

[生成 TrackMan 监督标签]
# 新增工具：export_trackman_labels.py（需新建）
python tools/export_trackman_labels.py --domain golf_ball_detection
  → datasets/processed/golf_ball_detection/trackman_labels.jsonl
     每条记录：{sampleId, ballSpeedMph, launchAngleDegrees, spinRateRpm,
                carryDistanceMeters, pixelsPerMetre, impactFrameIndex}

[质量校验]
python tools/validate_registry.py --strict
python tools/generate_quality_report.py
```

### 需要新建的工具

**`tools/export_trackman_labels.py`**
- 从 `samples.jsonl` 提取有 TrackMan 数据的样本
- 关联 `frames_index.jsonl` 找到 impact 帧
- 输出 `trackman_labels.jsonl`，每条含 sampleId + TrackMan 字段 + pixelsPerMetre
- 约 50 行

### 数据质量要求
- 每个样本必须有：视频 + LiDAR sidecar + TrackMan 至少 ballSpeedMph + launchAngleDegrees
- 目标采集量：每种球杆类型 ≥ 50 次挥杆（共 14 种球杆 × 50 = 700 次）
- 场地多样性：室内/室外、不同光线条件

## 流水线 2：模型训练到部署流水线

### 目标
训练两个模型：① 球检测模型（YOLO）；② 发射参数回归模型（从视频帧序列预测 ballSpeed/launchAngle/spin）。

### 模型 A：球检测模型（已有基础）

```
[输入]
datasets/processed/golf_ball_detection/{train,val,test}/
  + golf_ball.yaml

[训练]
cd tools/train_ball_detector
python train.py --data golf_ball.yaml --epochs 100 --device 0
  → runs/golf_ball/train/weights/best.pt
  → 目标：mAP@0.5 > 0.85

[导出 CoreML]
python export_coreml.py --model runs/golf_ball/train/weights/best.pt
  → GolfBallDetector.mlpackage
  → 复制到 projects/GolfBallDetectionApp/Resources/

[集成验证]
xcodegen generate --spec projects/GolfBallDetectionApp/project.yml
# 在 GolfBallDetectionApp 中用测试视频验证检测效果
```

### 模型 B：发射参数回归模型（新增，TrackMan 作为监督信号）

这是 TrackMan 辅助提升精度的核心：用 TrackMan 数据作为标签，训练一个从视频帧序列直接预测发射参数的模型。

```
[输入]
datasets/processed/golf_ball_detection/trackman_labels.jsonl
  + 对应的帧序列（impact 前后各 10 帧，共 20 帧）

[模型架构]
# 新建：tools/train_launch_estimator/train_regression.py
输入：20 帧灰度图（每帧 224×224）+ pixelsPerMetre
输出：[ballSpeedMph, launchAngleDegrees, backspinRPM]
架构：MobileNetV3-Small（特征提取）+ LSTM（时序）+ 3 输出回归头
损失：MSE，各参数归一化后加权（速度权重 0.5，角度 0.3，旋转 0.2）

[训练]
python tools/train_launch_estimator/train_regression.py \
  --labels datasets/processed/golf_ball_detection/trackman_labels.jsonl \
  --frames-dir datasets/raw/golf_ball_detection/frames \
  --epochs 50
  → runs/launch_estimator/best.pt
  → 目标：ballSpeed 误差 < 3mph，launchAngle 误差 < 1.5°

[导出 CoreML]
python tools/train_launch_estimator/export_coreml.py
  → LaunchParameterEstimator.mlpackage
  → 复制到 packages/GolfAnalysisKit/Resources/

[替换现有估算器]
# 修改 LaunchConditionEstimator.swift
# 优先使用 CoreML 模型推理，fallback 到现有查表法
```

### 需要新建的文件

| 文件 | 用途 | 约行数 |
|------|------|--------|
| `tools/train_launch_estimator/train_regression.py` | 发射参数回归训练 | 120 行 |
| `tools/train_launch_estimator/export_coreml.py` | 导出 CoreML | 30 行 |
| `tools/train_launch_estimator/dataset.py` | 帧序列数据集类 | 60 行 |

### 精度提升预期

| 参数 | 现有查表法 | TrackMan 监督模型 |
|------|-----------|-----------------|
| 球速 | ±3-5% | ±1-2% |
| 发射角 | ±2-3° | ±0.8-1.5° |
| 后旋 | ±200-500 RPM | ±80-150 RPM |
| 落点误差（Driver） | ±15-25 码 | ±5-10 码 |

## 流水线 3：正式 App 展示流水线

### 目标
用户在 GolfBallDetectionApp 中完成一次完整的"击球 → 分析 → 展示轨迹和落点"体验。

### 步骤

```
[准备阶段（击球前）]
1. 打开 GolfBallDetectionApp
2. LiDAR 标定（复用 LiDARCalibrationManager）
   → 获取 pixelsPerMetre, ballPosition3D, groundPlaneY
   → 存储为 CalibrationSnapshot

[录制阶段]
3. 点击录制 → AVFoundation 240fps@1080p
4. SwingAudioDetector 实时监听 → 检测 impact 时刻（±1ms）
5. 录制完成 → 视频保存到本地

[分析阶段（录制后，无时间压力）]
6. OfflineAudioAnalyser 精确定位 impact 帧
7. FusedBallDetector（YOLO + 帧差分）处理 impact 前后 30 帧
   → 获取球的像素轨迹点
8. LaunchParameterEstimator（CoreML 模型）推理
   → ballSpeedMph, launchAngleDegrees, backspinRPM
   （若有 TrackMan 数据则直接使用，精度更高）
9. TrajectoryFusionCoordinator（需新建）
   → LaunchConditions 构建
   → TrajectoryPhysicsModel.simulate() → TrajectoryResult
   → BezierTrajectoryModel 平滑
   → 米制坐标 → 屏幕像素坐标

[展示阶段]
10. VideoReplayView（已有）
    ├─ AVPlayer 0.1x 慢放
    ├─ TrajectoryOverlayView（已有）：弹道线 + impact 点 + 落地点
    └─ FlightDataPanel（已有）：球速、发射角、Carry、旋转、弹道形状

11. LandingComparisonView（需新建）
    ├─ 侧视图：轨迹高度曲线（TrajectoryResult.points 的 y 分量）
    ├─ 俯视图：预测落点（蓝色）vs GPS 实测落点（红色，若有）
    └─ 误差统计：预测 vs 实测的距离偏差

[数据回传（可选）]
12. 将分析结果导出为 sample record
    → 通过 import_ios_export.py 回传 Mac
    → 作为新训练数据，持续改进模型（数据飞轮）
```

### 需要新建的文件

| 文件 | 用途 | 约行数 |
|------|------|--------|
| `projects/GolfBallDetectionApp/.../TrajectoryFusionCoordinator.swift` | 分析阶段协调器（步骤 6-9） | 80 行 |
| `projects/GolfBallDetectionApp/.../LandingComparisonView.swift` | 落点对比视图（步骤 11） | 60 行 |
| `packages/GolfAnalysisKit/.../TrackManLaunchConverter.swift` | TrackMan → LaunchConditions | 20 行 |

### 需要修改的文件

| 文件 | 修改内容 |
|------|---------|
| `DatasetCollectorModels.swift` | `CollectorReferenceMeasurement` 新增 `spinAxisTiltDegrees: Double?` |
| `LaunchConditionEstimator.swift` | 优先使用 CoreML 模型，fallback 查表法 |

## 整体数据飞轮

```
有 TrackMan 采集（700 次）
    ↓
训练发射参数回归模型
    ↓
正式 App 无需 TrackMan，精度接近 TrackMan
    ↓
正式使用中持续采集数据（无 TrackMan）
    ↓
定期用新数据 fine-tune 模型
    ↓
精度持续提升
```
