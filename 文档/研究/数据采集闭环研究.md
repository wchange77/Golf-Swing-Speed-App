## 1. 收集什么数据（按域定义）

### 1.1 `human_club`（人体+球杆分析）

| 类别 | 必选字段 | 说明 |
|---|---|---|
| 样本标识 | `sampleId` `sessionId` `shotId` `takeIndex` | 形成“会话-镜头-重拍”闭环，避免重复采集 |
| 文件指纹 | `sha256` `hashAlgorithm` | 内容级去重，避免同文件重复入库 |
| 媒体信息 | `fps` `resolution` `capturedAt` | 速度估计与时序一致性所需最小信息 |
| 动作上下文 | `clubType` `handedness` `swingIntensity` | 支撑后续分层评估（不同杆型/挥速） |
| 质量标签 | `status` `tags` | 支撑归档、剔除与数据版本迭代 |

### 1.2 `golf_ball_detection`（高尔夫球检测）

| 类别 | 必选字段 | 说明 |
|---|---|---|
| 样本标识 | `sampleId` `sessionId` `shotId` `takeIndex` | 与人体球杆域保持同一索引体系 |
| 文件指纹 | `sha256` `hashAlgorithm` | 与另一域共享去重策略 |
| 媒体信息 | `fps` `resolution` `capturedAt` | 检测模型训练与时序对齐 |
| 场景上下文 | `surface` `lighting` | 球检测强依赖地面与光照变化 |
| 标注路径 | `annotationPath` | 允许 YOLO/COCO 两类标注共存 |

### 1.3 会话级公共字段（两个域共享）

| 字段 | 用途 |
|---|---|
| `device` `deviceProfile` | 设备可追溯（当前默认 `iphone17max` 档案） |
| `captureConfig` | 统一采集参数（FPS/分辨率） |
| `environment` | 场景类型、光照、三脚架、距离 |
| `targetDomains` | 明确本次会话采哪些域，防止后续混采 |

## 2. 数据如何保存（存储与契约）

### 2.1 存储分层

| 层 | 目录 | 作用 |
|---|---|---|
| 原始层 | `datasets/raw` | 哈希归档的原始资产与标注 |
| 注册层 | `datasets/registry` | 会话、样本、重复事件日志（JSONL） |
| 处理层 | `datasets/processed` | `train/val/test` 切分后训练可用目录 |
| 导出层 | `exports` | 总 manifest + 消费者专用 manifest |
| 分析层 | `analysis/reports` | 质量报告与覆盖统计 |

### 2.2 契约文件

| 契约 | 文件 |
|---|---|
| 会话记录 | `contracts/session_record.schema.json` |
| 样本记录 | `contracts/sample_record.schema.json` |
| 总清单 | `contracts/dataset_manifest.schema.json` |

每次写入样本/会话时都执行 schema 校验；`tools/validate_registry.py` 用于全量回归校验。

### 2.3 去重策略

1. 以 SHA-256 做内容去重（主键级）。  
2. 重复事件写入 `duplicates.jsonl`，不直接覆盖旧样本。  
3. 切分只基于 `status=active` 且去重后的样本。

## 3. 如何直接对接其他三个项目

### 3.1 消费者清单

| 消费者 | 清单文件 | 域 |
|---|---|---|
| 人体球杆分析 App | `exports/consumers/human_club_analysis_app.json` | `human_club` |
| 高尔夫球检测 App | `exports/consumers/golf_ball_detection_app.json` | `golf_ball_detection` |
| PiTrac 可行性研究 | `exports/consumers/pitrac_feasibility_study.json` | 两域 |

### 3.2 接入约定

- 两个 App 内桥接层优先读取各自专用环境变量：
  - `HUMAN_CLUB_MANIFEST_PATH`
  - `GOLF_BALL_MANIFEST_PATH`
- 若未设置，回退到 `DATASET_MANIFEST_PATH` 或默认相对路径。

## 4. iPhone 17 Max 采集闭环（执行模板）

### 4.1 会话启动

```bash
python tools/start_session.py \
  --collector "<name>" \
  --device "iPhone17Max" \
  --device-profile "iphone17max" \
  --fps 240 \
  --resolution 1920x1080 \
  --scene-type indoor \
  --lighting indoor_led \
  --tripod \
  --target-domains human_club,golf_ball_detection
```

### 4.2 样本入库

- 单样本：`tools/register_sample.py`
- 批量：`tools/register_batch.py`
- 强制包含 `sessionId + shotId + takeIndex` 以防重复采样失控。

### 4.3 质量关口

```bash
python tools/split_dataset.py --domain human_club --strategy session --seed 42
python tools/split_dataset.py --domain golf_ball_detection --strategy session --seed 42
python tools/generate_manifest.py
python tools/generate_quality_report.py
python tools/validate_registry.py --strict
```
