## 1. 高尔夫挥杆分析工具

### GolfDB / SwingNet
- **回购：** [麦克纳利/高尔夫数据库](https://github.com/wmcnally/golfdb)
- **技术堆栈：** Python、PyTorch
- **最后更新：** 维护； CVPR 研讨会 2019 论文
- **它的作用：** 用于高尔夫挥杆排序的视频数据库 - 检测修剪后的高尔夫挥杆视频中的 8 个挥杆事件（瞄准、脚趾向上、中后挥杆、顶部、中下挥杆、击球、中后挥杆、完成）。 SwingNet 是基线模型。
- **关键算法：** MobileNetV2 特征提取 + 用于时间排序的双向 LSTM。通过增强实现约 76% PCE。
- **数据集：** 来自 580 个 YouTube 视频的 1400 个视频剪辑，带有 8 个事件的帧级注释。混合慢动作/常规、男/女、多种俱乐部类型。
- **相关性：** 高 -- 直接适用于检测摆动阶段。事件检测模型可以识别撞击帧，这对于从视频中计算杆头速度至关重要。

### AICaddy - 高尔夫俱乐部追踪器
- **回购：** [oswinkil-git/AICaddy-A-高尔夫俱乐部-Tracer](https://github.com/oswinkil-git/AICaddy-A-Golf-Club-Tracer)
- **技术堆栈：** Python、YOLOv8
- **它的作用：** 使用在 6000 多张高尔夫球杆头图像上训练的自定义 YOLOv8 模型来追踪挥杆过程中的球杆路径。
- **关键算法：** YOLOv8 对象检测针对高尔夫球杆头检测进行了微调。
- **数据集：** 6000+ 带注释的高尔夫球杆头图像。
- **相关性：**非常高 -- 直接检测和跟踪视频中的高尔夫球杆头。检测模型可以通过跟踪跨帧的球杆头位置来输入速度计算管道。

### 高尔夫挥杆分析 (MediaPipe)
- **回购：** [HeleenaRobert/高尔夫挥杆分析](https://github.com/HeleenaRobert/golf-swing-analysis)
- **技术堆栈：** Python、MediaPipe Pose、OpenCV
- **它的作用：** 使用身体标志跟踪（耳朵、臀部、手腕）分析高尔夫挥杆，计算挥杆角度，覆盖参考轴，并生成带注释的视频。
- **关键算法：** MediaPipe Pose 用于 33 个身体标志，关节之间的角度计算。
- **相关性：** 高 -- 展示了一种可以在移动设备上运行的轻量级挥杆分析方法。身体姿势可以补充球杆追踪以进行整体分析。

### 挥杆改进的姿势估计
- **回购：** [Strojove-uceni/23206-最终姿势估计以改善挥杆](https://github.com/Strojove-uceni/23206-final-pose-estimation-for-swing-improvement)
- **技术堆栈：** Python，姿势估计模型
- **它的作用：** 使用姿势估计来分析高尔夫挥杆姿势并提供反馈。
- **关键算法：** 与参考摆动进行比较的姿势估计。
- **相关性：** 中等——注重形式而不是速度，但身体跟踪方法是相关的。### 分析.golf
- **回购：** [tlouth19/analyze.golf](https://github.com/tlouth19/analyze.golf)
- **技术堆栈：** React、Redux、Tailwind、Konva.js
- **它的作用：** 基于浏览器的高尔夫挥杆分析器，带有手动注释和绘图工具。
- **相关性：** 算法低，但对于挥杆分析应用程序有用的用户体验参考。

## 2. 高尔夫发射监视器和模拟器

### PiTrac - DIY 高尔夫发射监视器
- **回购：** [PiTracLM/PiTrac](https://github.com/PiTracLM/PiTrac)
- **网站：** [pitraclm.github.io/PiTrac](https://pitraclm.github.io/PiTrac/)
- **黑客日：** [hackaday.io/project/195042](https://hackaday.io/project/195042-pitrac-the-diy-golf-launch-monitor)
- **技术堆栈：** C++、Python、Raspberry Pi、Pi 全局快门相机
- **它的作用：** 世界上第一个免费、开源的高尔夫发射监视器。使用基于高速红外频闪的图像捕获确定球速、发射角度（水平和垂直）以及 3 轴旋转。
- **关键算法：** 用于高速捕捉的红外闪光灯照明、用于球位置/旋转检测的图像处理、基于物理的速度计算。
- **硬件：** 总计约 250 美元（2 个 Raspberry Pi + 摄像头）。使用 Pi 全局快门相机（约 50 美元）。
- **接口：** GSPro、E6/TruGolf 模拟器、独立网络应用程序。
- **相关性：**非常高——最直接相关的项目。演示相机图像的实际速度测量。根据帧间位移计算球速的算法可以直接转移。红外频闪方法很聪明，但手机应用程序不需要 - 然而，数学和校准逻辑是黄金。

## 5. 高速对象跟踪（TrackNet 及类似）

### TrackNet（官方）
- **论文：** [arxiv.org/abs/1907.03698](https://arxiv.org/abs/1907.03698)
- **网站：** [国立大学教育学院](https://nol.cs.nctu.edu.tw/ndo3je6av9/)
- **技术堆栈：** Python、深度学习（VGG16 + DeconvNet）
- **它的作用：** 深度学习网络专为跟踪运动中的高速和微小物体而设计。将多个连续帧作为输入并输出以球位置为中心的高斯热图。网球追踪准确率达到 99.7%，召回率达到 97.3%。
- **关键算法：** 采用 VGG16 编码器 + DeconvNet 解码器的 FCN 模型、用于时间学习的多帧输入、高斯热图输出。
- **相关性：**非常高 - 核心架构专为跟踪视频中小型、快速移动的物体（如球杆头）的问题而设计。多帧方法有助于解决运动模糊问题，这是高速高尔夫挥杆的一个关键挑战。

### TrackNet（PyTorch 非官方）
- **回购：** [yastrebksv/TrackNet](https://github.com/yastrebksv/TrackNet)
- **技术堆栈：** Python、PyTorch
- **它的作用：** TrackNet 的非官方 PyTorch 实现。
- **相关性：** 高 -- 更现代的框架实现，更容易集成。

### TrackNet - 羽毛球跟踪 (TensorFlow2)
- **回购：** [Chang-Chia-Chi/TrackNet-Badminton-Tracking-tensorflow2](https://github.com/Chang-Chia-Chi/TrackNet-Badminton-Tracking-tensorflow2)
- **技术堆栈：** Python、TensorFlow 2
- **相关性：** 中等——替代框架实施。

### TrackNet V4
- **网站：** [tracknetv4.github.io](https://tracknetv4.github.io/)
- **它的作用：** TrackNet 的最新发展，具有改进的性能。
- **相关性：** 高 - 具有最佳准确性的最新版本。

### 周末深度学习 TrackNet
- **回购：** [周末深度学习/TrackNet](https://github.com/weekenddeeplearning/TrackNet)
- **技术堆栈：** Python

## 7. 姿态估计框架

### MMpose (OpenMMLab)
- **回购：** [开放-mmlab/mmpose](https://github.com/open-mmlab/mmpose)
- **技术堆栈：** Python、PyTorch
- **星星：** 5,000+
- **最后更新：** 积极维护（v1.3.0 于 2024 年 1 月发布）
- **它的作用：** 综合姿势估计工具箱：2D/3D 人体姿势、手部姿势、面部标志、133 个关键点全身、动物姿势。包括 RTMPose，用于高精度和高速度的实时多人姿势估计。
- **关键模型：** ViTPose、RTMPose（实时）、HRNet、SimpleBaseline
- **相关性：** 高 -- RTMPose 对于实时移动应用程序来说足够快。高尔夫球手的身体姿势有助于计算身体旋转速度和顺序，这与杆头速度相关。

### 关键训练数据策略

1. 从 **Roboflow 高尔夫俱乐部跟踪数据集**开始（6,750 张图像）
2. 补充 **AICaddy 的 6,000 多张图片**（如果格式兼容）
3. Fine-tune **YOLOv8 Nano** for small model size on iPhone
4. 通过 Ultralytics 导出到 **CoreML**
5. 使用 **GolfDB** 进行挥杆阶段检测（识别击球周围的帧）
6.应用**卡尔曼滤波器**（来自高尔夫球检测论文）来平滑噪声检测

### 速度计算物理学

- 击球时球杆头速度：通常为 80-120 英里/小时（36-54 m/s）
- 在 240 FPS 下，杆头在接近撞击时每帧移动 6-9 英寸（15-23 厘米）
- 具有 1080p 输入的 YOLOv8 检测可以定位到 ~5-10 像素精度
- 通过适当的相机校准（已知到高尔夫球手的距离），像素位移可以转换为真实世界的距离
- 速度 = 像素位移 * (真实世界比例 / 每单位像素) / 帧时间增量
- 角动量：L = I * omega；球杆头速度 = omega * 球杆长度
