# 高尔夫挥杆速度应用程序 — 研究计划

> **目的：** 本文件概述了对所有现有高尔夫挥杆跟踪应用程序、软件、硬件系统、学术论文和使用摄像头（和相关传感器技术）测量高尔夫球杆杆头速度和挥杆指标的开源项目进行全面研究的研究简介。它作为执行和写入`文档/研究/研究总览.md`的规范。

---

## 研究目标

主要目标是为新 iPhone 应用程序的设计和开发提供信息，该应用程序使用设备的内置 LiDAR 传感器和高 FPS 摄像头来测量高尔夫球杆头速度，无需任何外部硬件。这项研究应该：

1. 绘制基于摄像头的高尔夫挥杆分析的整个竞争和学术格局
2. 确定仅使用智能手机摄像头进行球杆头检测和速度计算的最佳可用技术
3. 了解如何使用（或可以使用）LiDAR 和深度传感器进行挥杆跟踪校准
4.了解将像素运动转换为现实世界速度的数学和算法基础
5. 确定我们的应用程序可以解决的差距、限制和机会
6. 列出可以调整或改进的创新方法

---

## 我们正在建设什么（研究背景）

**应用程序概念：** iPhone 应用程序：
- 使用 iPhone 的内置 LiDAR 扫描仪进行初始设置校准 — 识别高尔夫球位置和球员的脚来定义挥杆捕捉区域
- 允许手动区域设置作为替代方案（用户点击屏幕来定义区域角/边界）
- 以最大 FPS 设置激活相机
- 位于**玩家前方**以捕捉高尔夫挥杆的完整弧线
- 使用计算机视觉自动检测球员何时准备挥杆（准备检测）以及何时完成挥杆（后续检测）
- 在整个挥杆弧线上跟踪球杆头
- 计算挥杆过程中每个点的杆头速度
- 识别**击球位置**（球所在的位置）并通过文本转语音读出该点的球杆头速度
- 保存每次挥杆的全速曲线和数据

**超出 v1 的范围：**
- 球追踪
- 球杆杆面角度
- 攻角
- 粉碎因素
- 发射角度
- 旋转速度
- 杆头速度以外的任何指标

### 4. 核心技术深入探讨

无论具体产品，深入研究并讲解以下基础技术：

#### 4a。用于快速对象跟踪的计算机视觉技术
- 光流（Lucas-Kanade、Farneback、RAFT 等）
- 背景扣除（MOG2、KNN 等）
- 模板匹配
- 轮廓检测和跟踪
- 斑点检测
- 用于运动预测的卡尔曼滤波
- 深度学习物体检测（YOLO、SSD等）应用于快速移动物体
- 点跟踪（TAPIR、CoTracker 等）

#### 4b。用于校准的 LiDAR 和深度传感
- iPhone LiDAR 的工作原理（ToF、范围、分辨率）
- 使用ARKit进行现实世界测量
- 使用深度数据设置校准区域
- iPhone LiDAR 在相关距离（1-5 米）的准确性和局限性

#### 4c。 iPhone 上的高 FPS 相机拍摄
- 每个 iPhone 型号的最大 FPS 功能（120fps、240fps、960fps 慢动作）
- 用于高 FPS 捕获的 AVFoundation API
- 权衡（分辨率与帧速率）
- 用于实时处理的缓冲区处理

#### 4d。速度计算数学
- 将像素位移转换为真实世界距离
- 透视校正和单应性
- 使用已知的参考距离（球位置、脚）进行校准
- 公式：速度=（现实距离）/（帧之间的时间）
- 考虑相机角度/正面视角
- 错误来源以及如何将其最小化

#### 4e。摆动检测（开始/结束自动化）
- 检测挥杆准备情况的方法（静止检测、姿势、握力检测）
- 检测摆动完成的方法（速度下降、后续弧完成）
- 用于运动开始检测的帧差分
- 高尔夫球手静止不动的背景建模

---

### 5. 需要识别的主要挑战

记录仅使用摄像头的球杆头跟踪中的已知难题：- 高球杆速度（100+ 英里/小时）时的运动模糊
- 通过撞击（球杆/球接触区）保持跟踪
- 可变的照明条件（室外、室内模拟器等）
- 球杆头遮挡（在某些挥杆位置位于身体后面）
- 前置摄像头角度的透视失真
- 用相似的颜色区分球杆头和身体/衣服
- 捕获和结果显示之间的延迟
- 高 FPS 捕捉期间的电池和热管理
- 精度与专业雷达系统的比较

## 研究质量标准

- 全面——宁可细节过多
- 尽可能引用带有 URL 的来源
- 明确区分：制造商声明、第三方评论、学术发现和合理推论
- 标记任何未知或无法验证的内容
- 对于学术内容：包括 DOI 和出版场所
- 对于开源：包括 GitHub 链接和星数
- 优先考虑深度而非广度——对 20 种产品进行彻底分析优于浅薄提及 50 种产品
