# 高尔夫挥杆测速系统 — 项目总览

> 状态：开发中（代码完成，真机验证阶段）
> 平台：iOS 17.0+（iPhone 12 Pro 及以上）
> 架构：四主项目 + 一个共享 Swift Package

---

## 一、项目定位

用 iPhone 内置 LiDAR + 240fps 摄像头测量高尔夫球杆头速度，无需外部硬件。

| 方案 | 成本 | 精度 | 便携性 |
|---|---|---|---|
| 专业发射监测器（Trackman、Foresight）| $10,000–$25,000+ | 优 | 低 |
| 消费级发射监测器（SkyTrak、Garmin R10）| $500–$2,500 | 良 | 中 |
| 本项目 | 免费（现有 iPhone）| 待验证（目标 ±3–5 mph）| 优 |

---

## 二、项目架构（数据先行）

```
DatasetCollectionPlatform（当前主焦点）
    ↓ 产出训练数据
HumanClubAnalysisApp          GolfBallDetectionApp
    ↓                              ↓
    └──────── GolfAnalysisKit ─────┘（共享算法包）
                                   ↓
                    PiTracIPhoneFeasibilityStudy（最后做）
```

### 执行顺序

1. **DatasetCollectionPlatform** — 先采集真实挥杆数据，建立数据闭环
2. **HumanClubAnalysisApp** — 人体+球杆分析，速度/姿态/挥杆链路
3. **GolfBallDetectionApp** — 高尔夫球检测+轨迹，依赖 YOLO 模型
4. **PiTracIPhoneFeasibilityStudy** — PiTrac 在 iPhone 复现可行性（最低优先级）

## 四、路线图

```
代码完成（当前）    M1 测试基线（4周）    M2 精度收敛（8周）    M3 发布候选（12周）
     │                    │                    │                    │
─────┼────────────────────┼────────────────────┼────────────────────┼──→
    现在                 ~5月底              ~6月底              ~7月底
```

### M1 — 测试基线
- DatasetCollectorApp 真机采集 50+ 组挥杆数据
- 两个 App 首次真机部署和基础功能验证
- 建立速度计算精度基线（对比测速仪）
- 训练首版球检测 CoreML 模型（YOLO）

### M2 — 精度收敛
- 累计 100+ 组挥杆数据，覆盖多场景/多球杆
- Kalman 滤波器和弹道参数调优
- 速度误差收敛到 ±5% 以内
- 球检测 mAP 达到可用水平

### M3 — 发布候选
- 完整回归测试套件
- Beta 测试（内部 + 小范围外部）
- App Store 提交准备
- PiTrac 可行性最终结论

### 关键阻塞项

1. **全部真机测试为零** — 无法验证任何精度指标（M1 首要任务）
2. **无训练好的球检测模型** — GolfBallDetectionApp 核心功能不可用（依赖数据采集）
3. **速度计算未经实测验证** — 核心价值主张未证实（M1 建立基线）
4. **PiTrac hardware_io 高风险** — 排最低优先级

## 五、技术要点

### 核心测速链路

```
LiDAR 校准（像素→真实世界比例）
    ↓
240fps 高速录制（AVFoundation）
    ↓
球杆头检测（YOLO CoreML + 帧差分）
    ↓
Kalman 滤波追踪（KalmanFilter6D）
    ↓
速度计算（帧间位移 / 实际时间戳）
    ↓
运动模糊补偿 + 挥杆平面修正
    ↓
冲击速度提取（音频触发精确定位）
```

### 精度目标

- v1 目标：±3–5 mph（对比 Garmin R10 等消费级设备）
- 传感器融合后目标：±2 mph

### 支持机型

| 机型 | LiDAR | 最大帧率 |
|---|---|---|
| iPhone 12 Pro/Pro Max | ✅ | 240fps |
| iPhone 13–17 Pro/Pro Max | ✅ | 240fps |
