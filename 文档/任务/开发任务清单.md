## 阶段 2 — 核心功能建设（自动跟踪）

### 2.1 场景与器材标定
#### 第 1 部分：场景搭建
- [x] 实现用于场景扫描的 ARKit 会话 (`LiDARCalibrationManager.swift`)
- [x] 通过 ARKit 平面检测识别地面（`ARPlaneAnchor` 分类）
- [x] 实现射线投射，允许用户在 3D 空间点击设置标定点
- [x] 使用 ARKit 计算标定点之间的真实距离
- [x] 基于 LiDAR 测量推导像素/米比例因子
- [ ] 构建带视觉反馈的标定 UI（AR 叠层显示已检测表面）
- [x] 优雅处理 LiDAR 不可用场景（回退到手动标定）
- [ ] 测试不同距离下的精度（1.5m、2m、2.5m、3m）*(需要真机)*

#### 第 2 部分：预备击球姿态分析（球员持杆站位）
- [x] 集成 `VNDetectHumanBodyPose3DRequest` 实现 3D 人体骨架检测（`LiDARCalibrationManager.analyseAddressPosition`）
- [x] 提取前导手臂关键点：肩、肘、腕的 3D 世界坐标
- [ ] 通过 CV 模型检测预备姿态下的杆头位置（静止状态无模糊，更易检测）
- [x] 从检测位置读取 LiDAR 深度，获取杆头 3D 位置 (`depthAtPoint`)
- [ ] 通过 CV 检测球的位置（白色球体检测）并结合 LiDAR 深度确认
- [x] 计算 **球杆长度**：手腕到杆头的 3D 距离 (`finaliseCalibration`)
- [x] 计算 **杆身倾角（lie angle）**：杆身向量（手腕→杆头）与地面的夹角
- [x] 将杆身倾角与预期范围（56–64°）校验，偏差过大时标记为检测错误
- [x] 计算 **预备姿态下的杆身平面**：穿过脊柱、双手和杆头的平面，用于预测挥杆平面
- [x] 计算 **手臂长度**：肩到手腕的 3D 距离（限制最大挥杆弧半径）
- [ ] 计算 **球到双手的几何关系**：定义预期击球区域的 3D 向量
- [x] 将所有推导结果作为标定约束保存 (`CalibrationSnapshot`)
- [ ] 向用户展示标定结果：球杆长度、杆身倾角、球位置确认状态
- [x] 允许用户选择球杆类型（木杆、铁杆、挖起杆）作为上下文

#### 第 3 部分：锁定与采集模式
- [ ] 用户确认后锁定标定数据
- [ ] 将约束传入卡尔曼滤波器：`club_length` 半径、`swing_plane`、最大速度边界
- [ ] 相机必须保持静止，检测到移动时给出警告
- [ ] **里程碑：** 完整标定链路打通，场景、人体和器材均完成测量并锁定
